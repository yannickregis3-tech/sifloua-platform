# Coding rules
- Use strict TypeScript and avoid `any`.
- Prefer Server Components; use Client Components only when interaction requires them.
- French UI, accessible semantic HTML, responsive/mobile-first layout.
- Curriculum data must be modular and accurately mapped.
- Never claim content is complete or officially validated without evidence.
- Privileged operations require server-side authorization.
- Schema changes require a migration and RLS review.
- Never commit secrets or personal learner data.
