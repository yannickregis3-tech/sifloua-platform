# SIFLOUA Platform

Plateforme éducative mobile-first pour la Côte d’Ivoire.

## Stack
- Next.js App Router
- TypeScript strict
- Supabase PostgreSQL et Auth
- GitHub pour le code source
- Vercel pour le déploiement web
- Cloudflare R2 pour les ressources pédagogiques

## État du projet
Fondation initiale en cours d’intégration. Les contenus pédagogiques, l’authentification et les parcours de données doivent être configurés et testés avant production.

## Sécurité
- Ne jamais committer de secrets ou de données personnelles d’apprenants.
- Toute table exposée doit avoir des politiques RLS testées.
- Les opérations privilégiées doivent être autorisées côté serveur.
